# UTP Malla Óptima / Academic Planner

Planificador curricular universitario offline-first, simulador de carga académica y proyector de costos para UTP.

## Scripts disponibles

- `npm run dev`: Inicia el servidor de desarrollo local de Vite.
- `npm run build`: Compila el proyecto con TypeScript y empaqueta la versión para producción.
- `npm run preview`: Previsualiza la versión compilada localmente.
- `npm run deploy`: Publica el build a GitHub Pages.
